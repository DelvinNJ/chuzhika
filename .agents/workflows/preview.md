description: Open the browser and visually check the site
---
1. Make sure the dev server is running (`npm run dev`). Start it if not.
2. Open http://localhost:3000 in the browser.
3. Scroll through every section and check layout, animations, and broken images.
4. Check mobile width (390px) and desktop width (1440px).
5. Report any visual bugs with a short list. Do not fix anything until I confirm.
